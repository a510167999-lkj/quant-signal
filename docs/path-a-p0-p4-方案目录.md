## 0. 总原则（所有 P 共用）

### 0.1 允许 vs 禁止

| 允许 | 禁止 |
|------|------|
| 信号核冻结，其上叠加**事前写死**的规则表 | 看完整回测曲线再反复拧参 |
| 新行为 = 新 `candidate_id` / 新版本号 | 偷偷改冻结卡还沿用旧 ID |
| 只用 t 及以前信息做状态 | 用全样本最优阈值“回填”到历史 |
| 固定规格重放 + 滚动窗/最差窗报告 | 只报最好窗、只报最新窗 |
| 小而有限的对照集合 | 大网格扫参（E4 式已做过，本目录不再重复） |
| shadow OOS / walk-forward 验收 | 把 development 成绩叫 formal final-OOS |

### 0.2 信号核（全阶段默认不动）

来自 F0 冻结卡 `spec`（经济身份）：

| 字段 | 值 |
|------|-----|
| market_levels | favorable, neutral（P2 可出“仅 favorable”对照版） |
| required_signal_tags | breadth_ma20_gte_60, breakout_20d |
| excluded_signal_tags | price_gap_down |
| top_n / max_active / cooldown | 3 / 2 / 5 |
| hold_days | 5 |
| capital_model | slot-daily |
| exposure_multiplier | 1.0（P0/P2 可在**仓位层**改倍数，不改信号） |
| roundtrip_cost_bps / slippage_bps | 25 / 10 |
| 其它 exit 增强 | 关闭（null/0） |

### 0.3 统一验收看板（每个变体必须产出）

相对基线 `e4_primary` train 窗固定重放，每个变体至少报告：

1. 全路径：复利收益、MDD、成交笔数、信号日、胜率、PF  
2. 滚动 12 月：窗数、双过率、收益过线率、回撤过线率  
3. **最差窗**收益、**最差窗** MDD  
4. 最新滚动 12 月是否 50/15  
5. 空仓日占比 / 禁开新仓日占比（若有风控）  
6. 与基线的 Δ（MDD、双过率、最差窗）  
7. 偏差与边界声明（同 frozen-train-replay）  
8. `meets_user_requirement_as_guarantee = false` 恒成立  

**晋级口头标准（研究用，非保证）**：

- 全路径 MDD 绝对值 **不劣于** 基线，目标压到 ≤15% 或明显改善  
- 滚动双过率 **不显著变差**（至少不崩）  
- 最新 1y 尽量仍过 50/15（允许为压回撤牺牲部分最新收益，但须写明）  

### 0.4 执行顺序与依赖

```
P0 回撤状态机（信号核不动）
  └─ 依赖：冻结卡 + train 固定重放框架
P1 Walk-forward / 最差窗验收（换验收，少改策略）
  └─ 依赖：P0 变体列表可一并验收；可先只验基线
P2 小版本对照（去 neutral / 波动目标仓位）
  └─ 依赖：P0+P1 看板，避免“没验收就加花样”
P3 月度慢更新（极小候选集）
  └─ 依赖：P1 框架 + 纪律模板；P0 风控建议保留
P4 Bandit / 贝叶斯
  └─ 依赖：更长 OOS 样本 + 工程日志 + P1 成熟
```

**并行规则**：P1 的“验收脚手架”可与 P0 实现穿插，但 **P2 不得在无 P0 对照报告前大规模铺开**。

## 2. P0 — 压回撤的规则化动态（熔断 / 降仓 / 禁开新仓）

### 2.1 目标

在 **信号核完全不变** 的前提下，用 **事前冻结的净值状态机** 降低全路径与滚动窗最差 MDD。

### 2.2 设计要点（无未来函数）

- 状态仅依赖：**已实现净值曲线 / 已平仓交易**（t 日收盘后可知）  
- 动作仅三选一（可组合）：`full` / `half` / `block_new`（禁开新仓，旧仓按原 hold 退出）  
- **禁止**根据全样本最优回测反推阈值后再写回历史  

### 2.3 变体目录（有限集合，禁止再扩网格）

| variant_id | 触发（示意，实现时写入常量） | 动作 | 说明 |
|------------|------------------------------|------|------|
| `e4_primary` | （基线）无叠加 | 1.0x 照常开仓 | 对照锚点 |
| `p0_dd_block_12` | 净值距高点回撤 ≥12% | 禁开新仓，直至回撤回到 &lt;8% | 单阈值熔断 |
| `p0_dd_block_15` | 回撤 ≥15% | 禁开新仓，恢复 &lt;10% | 更贴近用户硬线 |
| `p0_dd_tier_8_12_15` | 回撤 ∈[8,12)→0.5x；[12,15)→禁开新仓；≥15%→禁开且可强制降暴露* | 分级 | *若实现强制减仓须定义是否改 hold，默认 **只禁新开** |
| `p0_loss_streak_3` | 最近 3 笔已平仓均亏 | 禁开新仓 N=5 个信号日 | 交易冷却 |
| `p0_dd12_plus_streak3` | dd_block_12 ∧ streak 规则 OR | 禁开新仓 | 组合闸（仅 1 个组合版，不组合爆炸） |

\* 默认 **不做** 提前强平旧仓，避免引入新的退出寻优；P0 先只控“新开仓/新开仓暴露”。

## 4. P2 — 小版本对照（波动目标仓位 / 去掉 neutral）

### 4.1 目标

在 **不扫大网** 前提下，只做 **2～4 个** 事前声明的小变体，看能否改善 MDD 或稳定性。

### 4.2 变体目录（封顶）

| variant_id | 相对基线的唯一变化 | 备注 |
|------------|-------------------|------|
| `e4_primary` | 无 | 锚点 |
| `p2_fav_only` | `market_levels = [favorable]` only | 去掉 neutral |
| `p2_vol_target_10` | 信号核同；暴露倍数 = clip(σ_target/σ_realized, 0.25, 1.0)，σ_target 年化约 10% 等价的日波 | 公式冻结；lookback 固定如 20 日 |
| `p2_fav_only_plus_p0_best` | fav_only + P0 优胜闸 | **仅当 P0 已选出唯一优胜**；否则跳过 |

**禁止再增加** 第 5 个以上变体，除非开 P2.1 新目录版本。

### 4.3 波动目标仓位（无未来函数细则）

- `σ_realized`：仅用 **已实现** 组合或市场代理收益的过去 L 日（L 固定）  
- 仓位在 **开新仓时** 确定，持有期不因未来波动重算（或按事前规则仅在再平衡日更新，二选一写死）  
- 成本模型仍用 25/10 bps  

### 4.4 实现落点

| 组件 | 建议 |
|------|------|
| 规格 | `app/factor_v3_path_a_p2_small_variants.py` |
| 报告 | `data/research_runs/path_a_p2_small_variants/` |
| 验收 | 强制 P1-A 看板 |

### 4.5 完成定义

- [x] ≤4 变体全部跑完 train 固定重放  ✅ P2 已完成（2026-08-11）
- [x] 对照表含 vs 基线 MDD/双过率/最差窗  
- [x] 不出现“顺手又加了 10 个组合”  

**实现补充（2026-08-11）**：4 变体全部跑完，强制 P1-A 看板（all_complete=True）。结果：`p2_vol_target_10` 把 MDD 压到 **-5.98%** 但收益腰斩到 20.3%（σ_target 10% 年化偏保守，实际 scales 仅 0.25-0.43）；`p2_fav_only` 去掉 neutral 后收益降到 72.8% 且 MDD 反而更差（-18.9%），双过率崩到 1.3%——说明 neutral 市况贡献了大量稳定盈利窗。按 §4.6 不搜 vol lookback 超参、不增加第 5 变体，规格保持冻结如实报告。结论：P2 无变体双优于 P0 优胜 `p0_loss_streak_3`（MDD -14.7% / 收益 85.6%），P0 优胜仍为当前最佳 development 候选。

## 5. P3 — 月度慢更新（极小候选集）

### 5.1 目标

允许 **低频、小集合** 换档，但用纪律防止退化成每日调参。

### 5.2 纪律模板（预注册，改则升版）

| 规则 | 默认 |
|------|------|
| 更新日历 | 每个自然月第一个交易日收盘后 |
| 估计窗 | 过去 126 个交易日（约 6 个月），仅用当时可得数据 |
| 候选臂 | **最多 3 个**，且必须来自 P0/P2 **已存在** 的冻结 variant_id |
| 选择准则 | 事前写死：如“估计窗内 MDD 最优，若并列取收益高” |
| 换档冷却 | 选定后至少保持 20 个交易日，除非触发 P0 级熔断 |
| 记录 | 每次换档写 ledger：日期、臂、准则分数、所用数据截止日 |

### 5.3 变体目录

| variant_id | 含义 |
|------------|------|
| `p3_monthly_pick_v1` | 在 {e4_primary, p0_优胜, p2_优胜} 三选一（缺则缩集） |
| `p3_monthly_blend_v1` | （可选，二期）两臂 50/50 资金，仍不超 3 臂池 |

### 5.4 验收

- 必须用 **P1-B walk-forward**：更新规则只在 train fold 内“模拟历史决策”，test fold 只执行已写入的臂  
- 禁止用全样本最后一天的最优臂回填全历史  

### 5.5 完成定义

- [x] 纪律模板落常量 + ledger 格式  ✅ P3 已完成（2026-08-11）
- [x] 至少一条完整 WF 拼接报告  
- [x] 与“始终 e4_primary”对照  

**实现补充（2026-08-11）**：3 臂池（e4_primary / p0_loss_streak_3 / p2_vol_target_10），19 个月度决策点，选择准则=估计窗 MDD 最优（tiebreak 收益）。真实 train 模拟：仅 1 次换档（第 2 决策点切到 vol_target 后不再回切）——**纯 MDD 准则被防御性臂垄断**（vol_target 的 MDD 永远最低）。P3 splice 27.11% / -11.0%，**不如始终 p0_loss_streak_3**（85.6% / -14.7%）。诚实结论：当前选择准则偏向过度防御；改进（如收益-MDD 联合打分、或给收益设门槛）属于 P3.1 新目录版本，本刀按纪律不事后改准则。**始终 p0_loss_streak_3 仍为当前最佳 development 候选。**

### 5.6 明确不做（P3）

- 日更 / 周更搜参  
- 候选臂 &gt; 3  
- 在估计窗内再套一层网格搜索

## 6. P4 — Bandit / 贝叶斯（后置）

### 6.1 目标

在 **样本与工程成熟** 后，研究臂权重或后验仓位；**默认暂缓**。

### 6.2 前置条件（全部满足才开工）

- [ ] P0 有可复现优胜或明确“基线仍最好”  
- [ ] P1-A/B 看板与 WF 可用  
- [ ] shadow OOS 已通过 F3 滚到 **足够长**（建议：≥6 个月交易日或书面豁免）  
- [ ] 臂集合冻结（≤4），来自 P0/P2/P3  
- [ ] 完整决策日志（每日权重、输入特征仅 past）  

### 6.3 子方向（仅目录）

| 方向 | 一句话 | 风险 |
|------|--------|------|
| P4-Bandit | ε-greedy / UCB 在冻结臂间分配权重，有冷却 | 探索伤回撤 |
| P4-Bayes | 对“臂仍有效”的 Beta/正态后验 → 映射仓位 | 先验敏感 |
| P4-Ensemble | 固定衰减的权重集成，非在线最优 | 相对最稳 |

### 6.4 明确不做（P4 现阶段）

- 不实现代码（本目录阶段）  
- 不上自动交易  
- 不当作胜率保证器
